# Output

## Current Output

The bot currently displays the processed employee records using
an Automation Anywhere Message Box.

For each employee, the output includes:

- Employee ID
- Name
- Department
- Salary
- Salary Classification
- Status

## Salary Classification

| Salary Range | Classification |
|---|---|
| Less than 50,000 | Low |
| 50,000 to less than 80,000 | Medium |
| 80,000 or above | High |

## Output File

This version of the bot does not generate or modify an output
Excel file.

The processed results are displayed during bot execution.
